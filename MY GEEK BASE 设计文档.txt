《“MY GEEK BASE” 个人网站设计文档》
一、 项目概述
项目定位：一个集娱乐（小游戏）、实用工具（电费记录）与个性化互动于一体的个人门户网站。

技术栈：纯原生 HTML + CSS + 原生 JavaScript（不使用 Vue/React 等重型框架）。

部署方式：GitHub Pages 静态托管。

兼容性：移动端优先，完美适配手机端与电脑端。

二、 视觉与UI风格
核心主题：赛博朋克 / 极客风（深空灰背景，霓虹蓝/紫渐变点缀）。

质感设计：卡片使用毛玻璃效果（Glassmorphism），悬浮时带有呼吸发光边框。

字体与排版：现代化无衬线字体，极简卡片式布局，留白舒适。

三、 核心功能模块
1. 首页门户（index.html）
标题：居中大标题 “MY GEEK BASE”。

导航大厅：大卡片网格布局，作为各个模块的入口（如：游戏大厅、电费管家、关于我）。

2. 游戏大厅模块（games.html）
游戏 1：霓虹贪吃蛇：基于 HTML5 Canvas，带有霓虹渐变发光身体、支持触屏滑动和虚拟方向键、包含科技风 GAME OVER 弹窗。

游戏 2：极简 2048：支持键盘方向键与触屏滑动，带有合并缩放动效。

扩展性：每个游戏单独js，文件后续可按此结构无限添加新游戏。

3. 实用工具模块（tools.html ）
暂时留空，后续增加


4. 全局高级特效（提升高级感）
二次元看板娘：引入 Live2D Widget，在屏幕右下角常驻，支持跟随鼠标、眨眼、点击互动。

点击特效：引入轻量级 JS 库（如 mouse-animations），实现左键点击的“霓虹涟漪”与粒子爆发效果。

卡片悬停特效：引入 Hover.css 或纯 CSS 实现卡片的上浮、发光、轻微缩放。

动态背景：引入 tsParticles，实现底层缓缓流动的星空/代码雨粒子背景（z-index: -1）。
